# 谷歌相似图片搜索工具使用说明

版本：v1.1.0

## Windows 分发

`dist` 目录会生成两个程序：

- `谷歌图片搜索工具.exe`：图形界面版。
- `谷歌图片搜索工具-cli.exe`：命令行版。

## GUI 批量使用

1. 点击“选择文件夹”。
2. 如只处理当前文件夹，不勾选“包含子文件夹”。
3. 如需要处理子文件夹，勾选“包含子文件夹”，并设置“最大层数”。
4. 设置每张图片最大提取数量。
5. 点击“批量搜索文件夹”。

层数定义：选择的目录本身是第 1 层，最大层数 4 表示最多处理 `1(2(3(4)))`。

批量结果会按图片所在目录分别生成 TXT/CSV，并放在对应目录。

## CLI 示例

单图：

```powershell
.\谷歌图片搜索工具-cli.exe --image "D:\images\test.png" --max-results 50 --no-proxy
```

当前文件夹批量，不进入子目录：

```powershell
.\谷歌图片搜索工具-cli.exe --folder "D:\images" --max-results 20 --no-proxy
```

包含子目录，最多 4 层：

```powershell
.\谷歌图片搜索工具-cli.exe --folder "D:\images" --recursive --max-depth 4 --max-results 20 --no-proxy
```

Linux headless：

```bash
python3.10 googlesearchpicture.py --folder ./images --recursive --max-depth 4 --headless --no-proxy
```

只检测或下载 ChromeDriver：

```powershell
.\谷歌图片搜索工具-cli.exe --download-driver-only
```

## 支持格式

JPG / JPEG / PNG / WEBP / GIF。

批量模式会跳过非支持格式、伪图片和超过 5MB 的文件。
